# 포켓몬 도감 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PokeAPI 데이터로 1,025종을 한국어로 보여 주는 개인용 React 포켓몬 도감을 만들고, 단계마다 React 개념을 하나씩 설명하며 학습 노트를 남긴다.

**Architecture:** Vite로 만든 React 단일 페이지 앱이다. 데이터는 전부 PokeAPI GraphQL(`https://graphql.pokeapi.co/v1beta2`)에서 받고, 요청 코드는 `src/api/`에, API 응답을 화면용 모양으로 바꾸는 순수 함수는 `src/lib/`에 모은다. 테스트는 `src/lib/`의 순수 함수에만 Vitest로 붙인다. 한국어 번역이 없는 이름(타입 색, 성장 속도, 서식지 등)은 `src/data/`에 고정해 둔다.

**Tech Stack:** Node.js LTS, Vite(React 템플릿, JavaScript), React, React Router(`react-router` 패키지), Vitest, 일반 CSS

**Spec:** `docs/superpowers/specs/2026-10-27-pokedex-design.md`

## Global Constraints

- JavaScript만 쓴다 (TypeScript, Tailwind 없음). 꾸미기는 컴포넌트 옆의 일반 `.css` 파일로 한다.
- 화면에 나오는 모든 글은 한국어다. 한국어 데이터가 없을 때만 영어로 대체한다.
- 주소: 목록 `/`, 상세 `/pokemon/:id`
- 이미지: 공식 일러스트만 쓴다. `https://raw.githubusercontent.com/PokeAPI/sprites/master/sprites/pokemon/other/official-artwork/{id}.png`
- 도감 번호 표기: `#0006` (4자리, 0으로 채움)
- 목록은 종마다 기본 모습 하나, 도감 번호 순서다. 카드 이미지는 `loading="lazy"`로 넣는다.
- 필터: 세대·타입은 각각 단일 선택(기본값 「전체」). 검색어와 함께 세 조건을 모두 만족해야 보인다. 타입은 둘 중 하나만 맞아도 된다.
- 단계(Task)마다 실행되는 상태로 끝나고, git 커밋을 하고, `docs/learning/NN-제목.md` 학습 노트를 남긴다. 노트에는 ① 이번 단계에서 배운 개념 ② 핵심 코드 조각과 설명 ③ 직접 바꿔 볼 연습 거리 2~3개를 담는다.
- 코드는 초보자가 따라 읽을 수 있는 수준을 유지한다. 상태 관리 라이브러리, 데이터 패칭 라이브러리, UI 라이브러리를 쓰지 않는다.
- 각 Task가 끝나면 대화창에서 단계 설명을 하고, 사용자가 브라우저에서 확인한 뒤 다음 Task로 넘어간다.

3. **잘못된 상세 주소 (`/pokemon/abc`, `/pokemon/99999`):** 「포켓몬을 찾을 수 없어요」와 돌아가기 링크가 보여야 한다. → Task 5 `parsePokemonId` 테스트와 수동 확인
4. **한국어 설명이 없거나, 선택한 버전에 기술·출현 기록이 없는 포켓몬:** 빈 칸 대신 안내 문구가 보여야 한다. → Task 5 `normalizeDetail` 테스트, Task 8·9 수동 확인
5. **진화 링크를 빠르게 연달아 누를 때:** 늦게 도착한 이전 포켓몬 응답이 현재 화면을 덮어쓰면 안 된다. → Task 5 `useAsync` 정리(cleanup) 처리와 수동 확인
